# Exploration 2 — biology features and controlled validation

Exploration 2 tested an inference-safe Tier-A biology correction on top of frozen UNI2-h appearance features. It added matched-capacity and shuffled-feature controls, leave-family-out checks, learning-rate controls, exact local PUMA V17 evaluator parity, and a 30-run ten-epoch cached-head investigation. The resulting signal was modest and remained a GT-centred development result rather than end-to-end deployment evidence.

Start with `REPORT_EXPLORATION_2.md`. The complete retained epoch record is `COMPLETE_EPOCH_LEDGER.md`; machine-readable epoch histories are under `EPOCH_HISTORY`. Metrics and predictions are under `RESULTS`, code and configurations are under `CODE`, and visual diagnostics are under `IMAGES`.

Use `FILE_INDEX.csv` for the canonical inventory and `RELOCATION_MAP.csv` or `DUPLICATE_REFERENCES.csv` when tracing an old path.
