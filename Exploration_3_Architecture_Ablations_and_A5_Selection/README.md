# Exploration 3 — architecture ablations and A5 selection

Exploration 3 ran the main cached-feature architecture comparison across A0–A5 and related biology/mask controls. The fixed ten-epoch A5 interaction model was retained as the strongest next architecture. The archive preserves per-run and per-epoch evidence, negative results, confusion records, evaluator parity, and the exact distinction between fold-level, pooled, semantic, and ROI metrics.

Start with `REPORT_EXPLORATION_3.md`. Use `COMPLETE_EPOCH_LEDGER.md` for the exhaustive epoch record and `EPOCH_HISTORY`, `METRICS`, and `PREDICTIONS` for machine-readable outputs. Reproduction code and configurations are under `CODE`; figures and diagrams are under `IMAGES`.

Use `FILE_INDEX.csv` for the canonical inventory and `RELOCATION_MAP.csv` or `DUPLICATE_REFERENCES.csv` when tracing an old experiment path.

BioMask/Tier-B comparisons and other contaminated diagnostics remain explicitly labelled as such. They are preserved for auditability, not promoted to confirmatory findings.
