This protocol supersedes the Exploration3 ban on new representation experiments only. Stage1 and every original artifact are immutable. The new tree is a copy/index archive. Ground-truth-centered development scores do not establish clinical, SOTA, independent-patient or full-proposal performance.

## Finite A and B sequence
A0: exact A5 (27866params). A1: token containing transformed target coordinate; integer floor, clipped to16x16. A2: fixed Gaussian sigma1.5 patch units (9source pixels atFOV96); weighted sum of normalized encoder patch tokens. A3: 3x3 neighborhood around A1, clipped at borders. A4: equal-weight mean of separately nonaffine-layer-normalized CLS and Gaussian representation, followed by the same A5 input normalization. Same head/TierA in all arms. No trained pooling. Each A1–A4 has independently broken-coordinate control with uniform patch-grid center in[2,14]^2, RNG1701 per UID; same coordinates for train/validation and seeds. In addition compute the literal inter-row coordinate permutation; document why near-identical centered coordinates cannot form a strong negative control. Fixed off-center Gaussian at(+4,+4)patches is a supplementary representation diagnostic, no additional architecture search.

B1: A5 FOV96 plus zero-initialized low-rank additive context correction W8to10(P1536to8(LN(CLS64))), independent normalized input. B2:same for128. Duplicate96 instead of each extra scale is matched capacity control. B3:two such residuals64+128 only if both primary scale arms pass promotion independently. Extra rank8 projection Kaiming, finalzero, appearance/TierA initialization before extra modules. Initial primary B tests remain CLS-based to isolate scale from pooling; any combination with promoted A is a separate explicit confirmatory step.
