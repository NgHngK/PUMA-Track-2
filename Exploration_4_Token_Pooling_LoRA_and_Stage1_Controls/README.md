# Exploration 4 — token pooling, LoRA, and Stage-1 controls

Exploration 4 examined target-patch, Gaussian, neighbourhood, global-local, and multiscale representations; limited Q/V LoRA; clean mask networks; ROI-class sampling; Tier-A controls; and detector-held coordinate comparisons. The study found promising representation geometry but the preregistered confirmation did not authorize replacing Exploration 3 A5 at that stage.

Start with `REPORT_EXPLORATION_4.md`. The exhaustive epoch ledger is `COMPLETE_EPOCH_LEDGER.md`. Machine-readable histories, metrics, and predictions are separated under `RESULTS`; implementation and configuration material is under `CODE`; the retained visual diagnostic is under `QC`.

Use `FILE_INDEX.csv` for the canonical inventory and `RELOCATION_MAP.csv` or `DUPLICATE_REFERENCES.csv` when tracing an old experiment path.

Large token caches, proposal arrays, raw/preprocessed inputs, and checkpoints were intentionally removed. Their provenance and the resulting metrics remain in the retained manifests, ledgers, reports, and audit files.
