# Exploration 5 — A5 failure analysis and next-experiment design

Exploration 5 was a retrospective root-cause and representation-geometry investigation of the Exploration 3 A5 system. It analyzed 120 joint-training epochs, per-class stability, sampling exposure, data diversity, Tier-A confounding, confirmation errors, and cached UNI2 representation geometry. It did not train a new model. The conclusion was to retain A5 while preparing a better-admitted full-population experiment.

Start with `EXPLORATION5_ROOT_CAUSE_REPORT.md`, then consult `FULL_DATA_A5_PROTOCOL.md` and `PROMPT5_FINAL_DECISION.json`. Machine-readable epoch dynamics and metrics are under `RESULTS`; analysis and figure-generation code is under `CODE`; figures are under `FIGURES`.

Use `FILE_INDEX.csv` for the canonical inventory and `RELOCATION_MAP.csv` when tracing an old path. Exploration 6's historical copies of this report now resolve to the authoritative copy here.

The Exploration 5 evidence is diagnostic/exploratory and does not relabel retrospective findings as preregistered confirmation.
